# Daily Trivia 
A project created for my daily trivia fix, or when I need a brain break at work. As it is presently coded, it will provide ten open-answer question from a variety of pre-defined categories, though the code can be tailored to your own personal needs or preferences.

For best results, enter the prompt into the description of a GenAI project. This will allow for a dedicated space to play the trivia game, as well as for retention of past scores, category strengths, and any tuning instructions provided through the course of the trivia sessions.
